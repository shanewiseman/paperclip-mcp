# Changelog

All notable changes to Paperclip MCP will be documented here.

## 0.1.0 - 2026-07-28

- Add a schema-driven MCP gateway for all 590 operations in the supplied Paperclip OpenAPI.
- Add distinct inbound and upstream bearer-token boundaries, including tokenless Paperclip
  `local_mode`.
- Add hardened Docker Compose deployment, stdio transport, generated tool documentation,
  and native validation.
