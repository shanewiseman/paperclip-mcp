# Security policy

Report suspected vulnerabilities privately to the repository maintainers. Do not open a
public issue containing bearer tokens, Paperclip secret values, agent credentials, or
private API responses.

Supported releases are listed in `CHANGELOG.md`. This initial alpha should be deployed on a
trusted host with the default loopback port publication. See
[docs/security.md](docs/security.md) for the threat model and operator controls.
